AYAAN MULANI - STUDENT PORTFOLIO
================================

FILES
- index.html: portfolio content and sections
- style.css: responsive dark-theme styling
- script.js: mobile navigation and footer year

HOW TO RUN IN VS CODE
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Edit the placeholders before publishing.

IMPORTANT PERSONALIZATION
- Replace YOUR_EMAIL@example.com with your real professional email.
- Replace the LinkedIn and GitHub homepage links with your own profile URLs.
- Add your resume PDF link or file if you want a resume download button.
- Confirm the Agri-Connect technology stack. The project card currently reflects the technologies discussed, but includes a note to verify Java.
- Add the exact libraries, algorithm/model and dates for House Price Prediction only if you used them.
- You can add certificate images and project screenshots by placing image files in this folder and linking them from index.html.

PUBLISHING
You can publish this static website using GitHub Pages or another static website host.
Do not publish private information such as Aadhaar number, home address, passwords, or personal documents.


PROFILE PHOTO - IMPORTANT
1. Choose a clear, professional head-and-shoulders photo with good lighting and a simple background.
2. Copy your photo into the assets folder and name it: profile.jpg
3. Open index.html and find:
   <img class="profile-photo" src="assets/profile-placeholder.svg" ...
4. Change the image source to:
   src="assets/profile.jpg"
5. Save and refresh the browser.
Recommended image: portrait orientation, JPG or PNG, with your face centered. Avoid Aadhaar cards, certificates, or group photos.
